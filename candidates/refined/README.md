# Single-model refined candidate

Install requirements.txt in Python 3.12 with a compatible CUDA PyTorch build. Set SOLAR_TEST_IMAGES to the official test_images directory and run pipeline.ipynb. The notebook loads weights/model.pt and requires no retraining or private outputs.

This is a candidate, not a claim of a winning solution. provenance.json records validation scope, measured inference time, hardware, and hashes. Kaggle submission 57906671 completed with public PQ 0.34. The supplied CSV is the exact accepted file; provenance records the original pre-score run. See the project report for training and validation methodology.
